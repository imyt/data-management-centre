# Catalog Feature Module (`@/features/catalog`)

## Ownership
The Catalog module owns all business capabilities related to the enterprise data catalog, including:
- Hierarchical community & domain browsing
- Curated asset grid exploration and faceted filtering
- Concurrency lease status badges and draft revision indicators
- Deep asset inspection, draft editing, and visual difference detection
- Propose new asset workflow

## Routes Mounted
- `/catalog` &rarr; mounts `CatalogPage` from `pages/catalog-page/`

## State Boundary
- **Server State**: Managed strictly through TanStack Query options in `@/api/client` generated by `@hey-api/openapi-ts`. Never mirrored to client stores.
- **Client / UI State**: `useCatalogUiStore` in `stores/catalog.store.ts` manages modal open states and drawer tab navigation.

## Public Barrel Contract
All cross-module consumers import strictly from `@/features/catalog`. Internal paths (`@/features/catalog/pages/...` or `@/features/catalog/components/...`) are private.
